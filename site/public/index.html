A coding agent on the subscription you already pay for.

Describe a task in plain language. nod reads your code, runs your tests, edits the files and tells you when it's done. Sign in with ChatGPT or Grok. No API key, nothing billed per token.

$ bun install -g github:anturno/nod

Requires Bun 1.4+. Then nod login codex or nod login grok.

Why nod

  1. Uses your subscription

    Sign in with ChatGPT (Plus, Pro, Business, Enterprise or Edu) or Grok (SuperGrok or X Premium) and start working.

  2. You approve every command

    Each command is shown with a risk level before it runs. Approve it once, allow commands for the session, or deny it.

  3. Small enough to trust

    nod acts only through bash, the same commands you would type. No agent framework, no model SDK, and the whole codebase fits in an afternoon's reading.

  4. Switch models mid-conversation

    Move between ChatGPT and Grok models with /model without losing context.

  5. Measured, not guessed

    An eval suite of real tasks tracks how often the agent succeeds, how many steps it takes, and how much context it uses.

Nothing runs until you say so, and each command shows its risk level first.

How it works

A loop around a model with two tools: bash to act and task_complete to finish. Every command starts in a fresh shell, and its exit code and output go back to the model so it can recover from its own mistakes.

while (true) {
  const { content, toolCalls } = yield* llm.stream(messages, tools);

  if (calledTaskComplete)  return done("task_complete");
  if (aborted)             return done("interrupted");
  if (turn >= maxTurns)    return done("max_turns");
}

CLI

  • nodOpen the interactive shell
  • nod "<task>"Run one task and exit, for scripts and CI
  • nod loginSign in with codex or grok
  • nod modelsModels your plan can use
  • --yesRun commands without asking

Subscriptions

Sign-in uses the OAuth clients of OpenAI's Codex CLI and xAI's Grok CLI against their subscription backends. These aren't public APIs and can change without notice. Tokens stay in ~/.nod on your machine. You're responsible for following each provider's terms.

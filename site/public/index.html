A coding agent on the subscription you already pay for.

Describe a task in plain language. nod reads your code, runs your tests, edits the files and tells you when it's done. Sign in with ChatGPT or Grok. No API key, nothing billed per token.

$ curl -fsSL https://nod.anturno.cloud/setup.sh | bash

macOS and Linux. Then nod login codex or nod login grok. Prefer Bun? bun install -g github:anturno/nod. Read the installer first.

Why nod

  1. Uses your subscription

    Sign in with ChatGPT (Plus, Pro, Business, Enterprise or Edu) or Grok (SuperGrok or X Premium) and start working. Tokens stay in ~/.nod on your machine.

  2. Approves before acting

    Reads are free; edits, commands and external paths go through your rules. In auto mode a reviewer model settles the rest, in ask mode you do. Say yes once, or for the whole session.

  3. Shell-like UI

    A streaming transcript with each tool call folded to one line. Type / for commands, @ for files, $ for skills, ctrl+o for the full output. Sessions save, resume and recover.

  4. Context efficient

    Large tool results stay out of the window behind a handle the model can read on demand. AGENTS.md, skills and MCP schemas load bounded and only when they apply; long sessions compact themselves.

  5. Embeddable

    The same runtime is a library: createAgent() for a headless agent with your own tools, createTerminal() for the whole shell inside your app. In-process TypeScript on Bun, no addon.

  6. Editor-ready via ACP

    nod acp speaks the Agent Client Protocol over stdio, so any editor that supports ACP can drive nod with the same sessions, permissions and MCP servers.

Shortcuts

  • enterSend, or steer the active turn with a follow-up
  • shift+enterInsert a newline (alt+enter or \ then enter also work)
  • escInterrupt the current turn
  • ctrl+cClear the draft; with an empty draft, cancel; twice, quit
  • ctrl+oReview and full transcript, then left or right
  • up / downPrompt history at the edge of the draft
  • / @ $Commands, files, skills

CLI

  • nodOpen the interactive shell
  • nod ask "<task>"One request and exit; --json for scripts and CI
  • nod -rPick a saved session to resume
  • nod loginSign in with codex or grok
  • nod acpACP server for your editor
  • All commandsSessions, MCP, permissions, workspaces, upgrade

Subscriptions

Sign-in uses the OAuth clients of OpenAI's Codex CLI and xAI's Grok CLI against their subscription backends. These aren't public APIs and can change without notice. Tokens stay in ~/.nod on your machine. You're responsible for following each provider's terms.
